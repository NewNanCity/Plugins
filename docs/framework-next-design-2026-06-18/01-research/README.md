# Research

本目录保留调研材料和外部来源。它不作为最终框架 Interface 的主入口，而是作为设计证据、技术博客素材和推广材料来源。

## 文档

- [research-assets.md](research-assets.md): 调研资产库和可复用叙事。
- [external-pain-points.md](external-pain-points.md): 平台约束与社区痛点。
- [framework-comparison.md](framework-comparison.md): event、GUI、command 不同封装方式比较。
- [framework-comparison-followups.md](framework-comparison-followups.md): 调研后的设计取舍准则和写作角度。
- [related-work-other-capabilities.md](related-work-other-capabilities.md): scheduler、config、network、persistence/cache、diagnostics、integration 等相关工作。

## 使用规则

- 外部资料、链接、博客素材放这里。
- 不在这里定义最终 Interface。
- 对外写作时引用这里的材料，但以 `../00-overview/unified-framework-design.md` 和 `../02-runtime/` 草案为准。
